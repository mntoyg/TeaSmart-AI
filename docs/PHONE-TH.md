# เปิดแอปบนมือถือ

หน้านี้เขียนให้อ่านบนมือถือ เปิดจากแอป GitHub แล้วกดลิงก์ได้เลย
ขั้นตอนทั้งหมดอยู่ในเครื่องเรา ไม่มีรูปใบชาออกไปที่ไหน

สำหรับคนที่ต้องการรายละเอียดและตัวเลขที่วัดไว้ ดู [docs/DEMO.md](DEMO.md)
(ยังเป็นภาษาอังกฤษ กำลังแปล)

---

## ลิงก์

| ลิงก์ | ใช้ทำอะไร |
|---|---|
| **[เปิดแอป](https://192.168.0.32:5173/scan)** | `https://192.168.0.32:5173/scan` |
| **[โหลดใบรับรอง (root CA)](http://192.168.0.32:8081/)** | ทำครั้งเดียวต่อเครื่อง จำเป็นสำหรับ iPhone |

ลิงก์ทั้งสองใช้ได้เมื่อ **มือถืออยู่ wifi วงเดียวกับคอม** และ **เซิร์ฟเวอร์เปิดอยู่**
ถ้าเลข IP ของคอมเปลี่ยน ลิงก์จะใช้ไม่ได้ ต้องออกใบรับรองใหม่ (ดูท้ายหน้า)

---

## ทำไมต้องมีใบรับรอง

เบราว์เซอร์จะให้ใช้กล้อง ใช้งานออฟไลน์ และติดตั้งลงหน้าโฮม
ได้เฉพาะหน้าเว็บที่อยู่ใน **secure context** เท่านั้น
ไม่ใช่ว่าถูกบล็อก แต่ความสามารถเหล่านั้น **ไม่มีอยู่เลย** ในหน้าเว็บที่ไม่ใช่ secure context

`localhost` ได้รับการยกเว้นตามมาตรฐาน ทุกอย่างจึงทำงานบนคอม
แต่ `http://192.168.0.32:5173` ไม่ได้รับการยกเว้น
เราจึงให้เซิร์ฟเวอร์เสิร์ฟเป็น `https://` ด้วยใบรับรองที่ออกเองในเครื่อง
และมือถือต้องเชื่อผู้ออกใบรับรองนั้นก่อน จึงต้องโหลด root CA ลงเครื่องครั้งเดียว

## iPhone

1. ต่อ wifi วงเดียวกับคอม
2. เปิด **Safari** (ไม่ใช่ Chrome) แล้วกด [โหลดใบรับรอง](http://192.168.0.32:8081/)
3. Safari จะถามว่าจะอนุญาตให้ดาวน์โหลด configuration profile หรือไม่ → **Allow**
4. **Settings** → บนสุดจะมีแถบ **Profile Downloaded** → แตะ → **Install**
   (ใส่รหัสปลดล็อกเครื่อง) → **Install** อีกครั้ง
5. ขั้นนี้ห้ามข้าม: **Settings → General → About → Certificate Trust Settings**
   → เปิดสวิตช์ของ **mkcert** ให้เป็นสีเขียว
   ถ้าไม่เปิด โปรไฟล์ติดตั้งแล้วแต่ยังไม่ถูกเชื่อถือ และหน้าเว็บจะยังขึ้นเตือน
6. กด [เปิดแอป](https://192.168.0.32:5173/scan) ต้องไม่มีคำเตือนเรื่องความปลอดภัย
   และต้องเห็นรูปกุญแจในแถบที่อยู่
7. ติดตั้งลงหน้าโฮม: ปุ่ม **แชร์** → **Add to Home Screen** แล้วเปิดจากไอคอน ไม่ใช่จากแท็บ

**ข้อควรรู้เฉพาะ iPhone**

- ทำขั้นที่ 2 ใน Safari เท่านั้น Chrome บน iOS ติดตั้งโปรไฟล์ไม่ได้
- หลังติดตั้งใบรับรองแล้ว Chrome บน iOS ใช้ได้ด้วย เพราะใช้ที่เก็บใบรับรองของระบบร่วมกัน
- การอัดวิดีโอใช้ **Screen Recording** ของ iOS เอง
  (Settings → Control Center → เพิ่ม Screen Recording) ไม่ต้องต่อคอม

## Android

ทำได้สองทาง เลือกทางใดทางหนึ่ง

**ทาง USB — แนะนำ ถ้าจะอัดวิดีโอบนคอม**
ไม่ต้องใช้ใบรับรองเลย เพราะ `adb reverse` ทำให้มือถือเปิด `localhost` ได้
ซึ่งได้รับการยกเว้นอยู่แล้ว ดูขั้นตอนใน
[docs/DEMO.md](DEMO.md) หัวข้อ *Testing on a real phone*

**ทางใบรับรอง — ถ้าไม่อยากต่อสาย**
1. กด [โหลดใบรับรอง](http://192.168.0.32:8081/)
2. **Settings → Security → More security settings → Encryption & credentials
   → Install a certificate → CA certificate → Install anyway**
   แล้วเลือกไฟล์ที่โหลดมา
   (เมนูนี้ชื่อไม่เหมือนกันทุกรุ่น ลองค้นคำว่า *certificate* ในหน้า Settings)
3. กด [เปิดแอป](https://192.168.0.32:5173/scan)

## สิ่งที่ต้องเปิดบนคอมก่อน

สามอย่าง แต่ละอย่างคนละหน้าต่าง

```bash
cd backend && .venv/Scripts/python.exe -m uvicorn app.main:create_app --factory --port 8000
```

```bash
cd frontend && TEASMART_DEV_CERT_DIR=../.certs npm run dev -- --host
```

```bash
python scripts/serve_ca.py
```

อันที่สามเปิดเฉพาะตอนจะโหลดใบรับรอง ติดตั้งเสร็จแล้วปิดได้เลย
ไม่ต้องเปิดไว้ตอนเดโม

ถ้ามือถือเปิดหน้าเว็บไม่ขึ้นแต่คอมเปิดได้ เกือบทุกครั้งคือ
**Windows Firewall บล็อกขาเข้าพอร์ต 5173** ต้องอนุญาต Node สำหรับเครือข่ายส่วนตัว
หรือเพิ่ม rule ให้พอร์ตนั้น

## ถ้าเลข IP เปลี่ยน

ใบรับรองผูกกับเลข IP ย้าย wifi หรือเราเตอร์แจก IP ใหม่แล้วจะใช้ไม่ได้
ดูเลขใหม่ด้วย `ipconfig` แล้วออกใบรับรองใหม่:

```bash
mkcert -cert-file .certs/dev-cert.pem -key-file .certs/dev-key.pem <ไอพีใหม่> localhost 127.0.0.1 ::1
```

แล้วรีสตาร์ท Vite ไม่ต้องติดตั้ง root CA บนมือถือใหม่ เพราะผู้ออกใบรับรองยังเป็นรายเดิม
ส่วนลิงก์ในหน้านี้ต้องแก้เลขตาม

---

## ถ้าอยากให้เบราว์เซอร์บนคอมเชื่อด้วย

คำสั่งนี้เขียนลงที่เก็บใบรับรองของ Windows เป็นการตั้งค่าความปลอดภัยของเครื่อง
**ผู้ใช้รันเอง** ไม่ให้ AI รันให้:

```bash
mkcert -install
```

ไม่จำเป็นต่อการเดโมบนมือถือ มีผลแค่กับเบราว์เซอร์บนคอมเท่านั้น
