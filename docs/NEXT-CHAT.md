## 4. ตัวเลขที่พูดผิดแล้วเสียหาย

- **ไม่มีค่า sensitivity ของการตรวจใบไหม้ และห้ามอ้าง รวมถึงบนเวที**
  มีแต่ specificity **97.18%** — `docs/EVIDENCE.md` หัวข้อ 5.5
- **specificity สูงอาจแปลว่าตัววิเคราะห์ไม่ได้มอง** การรันครั้งแรกได้ 99.22%
  ขณะที่หาแผลไม่เจอบนใบที่เป็นโรค **59%**
- **accuracy 0.987 เป็นขอบบน ไม่ใช่ค่าประมาณในสนาม** การแบ่งชุดไม่ได้จัดกลุ่มตามครั้งที่ถ่าย
- **ตัวจำแนกผิดได้แบบมั่นใจ** มีภาพทดสอบหนึ่งภาพผิดที่ **0.983**
- **ไม่มีภาพใดในคลังมาจากสิงห์ปาร์ค**
- **threshold ด่าน 1 และ `min_confidence` วัดมาแล้ว — วัดใหม่ ห้ามขยับมือ**

## 5. กับดักที่เสียเวลาไปแล้ว อย่าเสียซ้ำ

- **`frontend/public/` คือพื้นผิวเผยแพร่** Vite ก็อปทุกไฟล์ลง `dist`
  `git ls-files --others frontend/public` ต้องว่าง มี test เฝ้าแล้ว
- **เดาแล้วแก้ช้ากว่าอ่าน** Sonar แดงครึ่งวันเพราะแก้สิ่งที่ linter เราเองชี้ ไม่ใช่สิ่งที่มันชี้
- **ตรวจ input อ่อนกว่าไม่รับ input** ตัด `--base-url` ทิ้งจบ ตรวจ host ไม่จบ
- **shell ของ agent เขียนไฟล์นอก repo แล้ว shell ผู้ใช้อาจไม่เห็น** ของที่โพรเซส
  ผู้ใช้ต้องอ่าน (CA, credential) ต้องสร้างใน terminal ของผู้ใช้
- **base ของ PR อาจไม่ใช่ `main`** เช็ก `git merge-base --is-ancestor HEAD origin/main`
- **ห้าม `grep -rn` จาก root** เดินเข้า `.venv` สองต้นและ `data/` แล้วชน timeout
- **`./scripts/test.sh` ก่อน push ทุกครั้ง** CI เคยจับของพังจากการรันแค่ชุดเดียว
