## D-008 เว็บสาธารณะคือแอป `frontend/`
เหตุผล: repo มีสองหน้า — `frontend/` ที่โหลดโมเดล ONNX บนเครื่องและเรียก `/api/v1/scan`
กับหน้าตัวอย่างที่ราก repo (`src/`) ซึ่งไม่มีโมเดลและสุ่มผล งานทุกเฟสต่อจากนี้ทำใน `frontend/`
เพื่อให้ฟีเจอร์ใหม่อยู่บนแอปที่ให้ผลจริง / ผลกระทบ: `vercel.json` ชี้ `root: frontend`,
เอกสารใน project-brain อ้างพาธภายใต้ `frontend/src` / วันที่ 2026-11-03 / ตัดสินใจโดยทีม frontend
หลังพบว่าเว็บเคยขึ้นหน้าตัวอย่างแทนหน้าโมเดล

## D-009 ส่วนหัวบนมือถือไม่ใช้ backdrop-filter
เหตุผล: `backdrop-filter` ทำให้ `.app-header` กลายเป็น containing block ของลูกที่ `position: fixed`
เมนูล่าง `.mobile-nav` (อยู่ใน header) จึงไปเกาะใต้ส่วนหัวแทนขอบล่างจอ / ผลกระทบ: ที่จอ ≤680px
header ใช้พื้นทึบ 97% แทนเบลอ; เดสก์ท็อปยังเบลอได้เพราะเมนูล่างซ่อนอยู่ / วันที่ 2026-11-03 / ทีม frontend

## D-010 สีที่ขึ้นกับธีมย้ายเป็น token ทีละส่วน
เหตุผล: ไฟล์ CSS สองไฟล์ (`index.css`, `styles.css` ของเดิม) มี hex ฝังอยู่มาก การเขียนใหม่ทั้งไฟล์เสี่ยงพังหน้าเดิม
ผลกระทบ: ธีมมืดใช้ `--surface --surface-soft --text --muted --line` และชุดมืดใน `:root[data-theme="dark"]`
ส่วนที่ยังใช้สีตายตัว (เช่น ป้ายสีเหลืองของโรค) override เฉพาะ selector ท้าย `index.css`
Toast สูงสุด 3 รายการ บนมือถืออยู่เหนือเมนูล่างและปุ่มค้นหา / วันที่ 2026-11-03 / ทีม frontend

## D-011 API เต็มรันคู่กับ frontend บนเครื่อง ไม่ได้ฝังในฟังก์ชัน Vercel
เหตุผล: `POST /api/v1/scan` บนโฮสต์สถิตได้ 405 หน้าเว็บจึงควรตกไปโมเดลบนเครื่อง
ลองเพิ่ม FastAPI เป็น Vercel service แล้ว preview `teasmart-nu2a2p6jv` ล้มด้วย
`Total bundle size (317.28 MB) exceeds the maximum function size` จาก onnxruntime กับ opencv
ผลกระทบ: `vercel.json` ยังเสิร์ฟเฉพาะ frontend รันร่วมกันด้วย `npm run dev` ที่ proxy `/api` ไป `127.0.0.1:8000`
(`app.asgi:app`) โมเดลไฟล์เดียวใน git ถ้ามีก็อปใน `backend/model/` ซึ่ง gitignore จะถูกใช้ก่อน
หน้าเว็บถือ 404/405 ที่ไม่มี `detail_th` ว่าไปไม่ถึง API / วันที่ 2026-11-06 / ทีม frontend
