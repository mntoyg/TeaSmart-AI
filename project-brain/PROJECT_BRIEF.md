# PROJECT BRIEF — TeaSmart

## หนึ่งประโยค
เครื่องมือช่วยคัดกรองโรคใบชาเบื้องต้นสำหรับเกษตรกร: สแกนใบ → รู้โรค → รู้ว่าควรทำอะไรต่อ

## ผู้ใช้หลัก
เกษตรกรชาที่ใช้มือถือในแปลง (แสงจ้า เน็ตไม่แน่นอน มือเปื้อน) และผู้ดูแล/เจ้าหน้าที่ส่งเสริมการเกษตร

## 3 ฟีเจอร์แกนหลัก (ห้ามทำให้ซับซ้อนจนบังสามอย่างนี้)
1. สแกนภาพใบชา
2. บอกโรค (คลาสหลัก: Tea Grey Blight, Tea Brown Blight, Algal Leaf Spot, Healthy และ other_disease เมื่อโมเดลไม่มั่นใจ)
3. บอกแนวทางแก้ไขเบื้องต้น

## ฟีเจอร์เสริมที่มีแล้ว
เช็กก่อนอ่านผล (readiness + แผนวันนี้), คลังความรู้, ประวัติการสแกนใน IndexedDB, ตรวจคุณภาพภาพ, ประเมินบนอุปกรณ์เมื่อไม่มีเซิร์ฟเวอร์, คิวส่งซ้ำ, PWA

## สิ่งที่โปรเจกต์ "ไม่ใช่"
- ไม่ใช่เครื่องมือวินิจฉัยแทนผู้เชี่ยวชาญ
- ไม่ใช่ระบบสั่งยา

## เกณฑ์ว่าดี (สำหรับแข่ง/เดโม)
- เดโมจบใน 60 วินาทีโดยไม่ต้องอธิบาย
- ใช้บนมือถือได้จริง ใช้ keyboard ได้เร็วบนเดสก์ท็อป
- บอกตรง ๆ เมื่อไม่แน่ใจ (ไม่โอ้อวดความมั่นใจ)
